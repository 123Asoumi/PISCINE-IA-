-Différence entre un environnement virtuel et ton Python global ?
Un environnement virtuel est une boîte isolée de librairies propre à un projet ; le Python global est partagé par toute la machine.
Pourquoi ignore-t-on .venv/ dans Git ?
Le .venv est lourd, lié à ta machine (chemins/binaires locaux) et régénérable → inutile et encombrant à pousser.
Avec tes mots : que contient un modèle après entraînement ?
Un modèle entraîné contient surtout ses paramètres (poids) ajustés pendant l’apprentissage — pas les données elles-mêmes.
